# 《AI陪伴微信机器人》使用手册 v4（2026-09-13 第三次改版）

> 写给"家长"：零代码，跟着点就行。v4 对应 **8 页签后台 + 世界引擎成为唯一权威**。

## 一、入口就两个

| 入口 | 地址 | 干什么 |
|---|---|---|
| **后台控制台** | `http://127.0.0.1:43121/console` | 管她的一切（8 个页签） |
| **她的房间** | `http://127.0.0.1:43121/room` | 跟她测试聊天（会进她的记忆） |

## 三、首次配置（最小可用）

1. **接大脑**：大脑页 → ①对话接口填 BaseURL+Key → 拉取 → 点模型 → 保存
2. **给灵魂**：她页填人设（或女娲捏）→ 保存人设
3. **接世界引擎（独立！）**：**世界**页 → 世界引擎 BaseURL+Key（建议与对话不同家）→ 拉模型 → 保存。不配=她今晚没剧本（随机兜底）
4. **绑定**：首页扫码绑定小号 → 启动
5. **定主人**：发条消息 → 你们页点 ID 戴👑
6. **记忆引擎**：重启 DSH 自动拉起；没起来双击「启动记忆引擎.bat」

## 四、世界引擎（她的世界怎么活过来）

- 每晚她睡着后自动跑一次：写日记 / 排明天作息（剧情熬夜→赖床）/ 定心情与痴迷 / 生活流水入记忆 / 冒念头 / 攒小秘密 / 更新天气 / 重写画像 / 维护社交圈（稳定编制 ≤6 人）/ 推进长线小心思 / 写下"今天状态一句话、今晚是否失眠、明天要不要找你·大概几点、她的作息基准" / 满周做性格结算
- 只走自己的独立 API，**绝不蹭对话接口**；失败 30 分钟后再试；没配置=随机兜底
- **「世界」页是它的家**：运行状态·上帝视角能看到它写的每一个值；「她的日记」有月历，一天一份存档（`diary/<日期>.md`，记事本能直接打开、永久保存）
- **「立刻生成一次世界」**：默认补今天；也可以填一个过去的日期补那一天（补完日历上就多点一天）
- 实况页 🌍 徽章=今天由世界引擎书写；🌤 徽章=今天天气

## 五、她的人格怎么"活"

- **六维**：MBTI→八维栈自动推导，可微调；每天有因果漂移（熬夜次日电量低），第二天弹回
- **性格演化**：每满 7 天，世界引擎按被哄/被怼/聊天量微调六维（合计≤±5），永不违背她的认知类型
- **分寸**（第三次改版）：**不再有亲密度/关系阶段这套数值**。她今天该多熟、怎么称呼你、能不能撒娇、要不要主动找你，全部由世界引擎每晚综合判断，写成一份"今天的分寸"；后台「世界」页能看到它写的分寸与由来。世界引擎没跑时走一套与关系无关的自然默认（客气、有边界感）
- **称呼**：你填的「专属昵称」她心里知道，**熟度够了才会自然叫出口**；勾了「锁定称呼」就不管分寸都用它
- **她自己改称呼**：**她不会自己偷偷换**——想让她换个更贴合的叫法，去「你们→称呼与关系」点「让她现在想一个」，由她自己的模型决定要不要改、改成什么，并写一句理由；改名记录在下面，也可以锁死不让她改
- **职业**：在「她是谁」里填职业名 → 机器判断怎么上班（世界引擎优先 → 模型推断 → 关键词兜底），结果显示在「她→生活节奏→**她的工作**」里，判错可手改或重判。强度滑杆 0-200% + 四个开关。注意：**职业不改她的六维底色**——职业决定她遇到什么事，性格决定她怎么反应
- **压力阈值只读**：三个阈值由她的性格算出来（秩序感→耐操／依恋→易崩／锐度→狠度／温度→冷淡），后台只显示数值和成因——想让阈值变，改她的性格
- **六个接口体检**：大脑页每个接口两个按钮——「测连通」零成本验地址/钥匙/模型名；「真跑一次」发最小请求看真结果（识图会自动画张测试图让她认、语音识别会先合成一句话再喂回去、**向量会量出维度并记下来**）。失败会给具体建议
- **变形**：压力累积会 Grip/Loop/Shadow，被哄/好睡眠恢复，长期更成熟（整合度）

## 五点五、她会"变形"，也记得自己说过什么

- **变形状态机**（「她」页有卡）：压力攒到阈值她会真的变——劣势爆发(说话冲/较真/说反话) → 反刍循环(绕不出来/封闭) → 影子状态(说平时绝不会说的话)；被哄、睡得好、时间都会减压，缓过来那一轮她会自己道歉或自嘲；每缓过来一次"整合度"+2。开关与灵敏度能调，**三个阈值只读**（由性格推）
- **双向记忆**（「记忆」页有卡）：她不但记得你说过什么，还把自己表态过的话（"我下周要去趟杭州"）单独归档；聊天时会像真人一样接得上自己上次说的，不会前后矛盾。可以关，也可以直接改/删这些"她自己的话"
- **记忆三类归属**：我 / 她 / 世界；一律中文（只有原话本身是英文才保留）。每条还有**一个桶**（会淡忘 / 固化 / 她自己的感受）决定它会不会被忘；归属与桶都在列表里直接改，不用进「详情」
- **向量接口**（「大脑→⑥向量接口」）：填地址即可，程序自动认出是本地 Ollama 还是云端接口；点「真跑一次并记下维度」会把维度量出来写进配置。**换向量模型前先看维度**——新模型维度和旧记忆库不一样时必须重建，否则引擎会直接拒绝启动并告诉你怎么做（不会静默出错）

## 六、常见问题

- **她不回消息？** 首页在线？急停没解除？安静时段？小号解封了吗？
- **世界引擎没动静？** 「世界」页看 API 状态灯；必须独立配置；「立刻生成一次世界」手动试跑
- **「她的日记」显示"加载失败"？** 说明**运行中的 DSH 还是旧代码**——重启 DSH 后这个接口才存在
- **生活节奏改了没效果？** 记得点卡里的「保存生活节奏」按钮；注意**作息以世界引擎为准**（它每晚推的会覆盖你手改，并且会留痕告诉你改了什么）
- **记忆引擎未运行？** 记忆页看灯；双击「启动记忆引擎.bat」
- **想让她彻底安静？** 右下角急停
- **数据在哪？** `~/.dsh/wechat-companion/`（备份这个目录=备份她；`diary/` 是她的日记档案）
