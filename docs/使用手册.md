> 写给"家长"：零代码，跟着点就行。v3 对应 7 页签后台 + 世界引擎全接入版。

| 入口 | 地址 | 干什么 |
|---|---|---|
| **后台控制台** | `http://127.0.0.1:43121/console` | 管她的一切（7 个页签） |

## 三、首次配置（最小可用）

1. **接大脑**：大脑页 → ①对话接口填 BaseURL+Key → 拉取 → 点模型 → 保存
2. **给灵魂**：她页填人设（或女娲捏）→ 保存人设
3. **接世界引擎（独立！）**：她页底部 → 世界引擎 BaseURL+Key（建议与对话不同家）→ 拉模型 → 保存。不配=她今晚没剧本（随机兜底）
4. **绑定**：首页扫码绑定小号 → 启动
5. **定主人**：大号发条消息 → 你们页点 ID 戴👑
6. **记忆引擎**：重启 DSH 自动拉起；没起来双击「启动记忆引擎.bat」

## 四、世界引擎（她的世界怎么活过来）

- 每晚她睡着后自动跑一次：写日记 / 排明天作息（剧情熬夜→赖床）/ 定心情与痴迷 / 生活流水入记忆 / 冒念头 / 攒小秘密 / 更新天气 / 重写画像 / 维护社交圈（稳定编制≤6人）/ 推进长线小心思 / 满周做性格结算
- 只走自己的独立 API，**绝不蹭对话接口**；失败 30 分钟后再试；没配置=随机兜底
- 「她」页：📖折页看详解；「她的天气」卡有真实天气开关（城市=人设城市，API 失败她自己编）；「她的社交圈」卡看编制
- 实况页 🌍 徽章=今天由世界引擎书写；🌤 徽章=今天天气

## 五、她的人格怎么"活"

- **六维**：MBTI→八维栈自动推导，可微调；每天有因果漂移（熬夜次日电量低），第二天弹回
- **性格演化**：每满 7 天，世界引擎按被哄/被怼/聊天量微调六维（合计≤±5），永不违背她的认知类型
- **称呼**：亲密度推着阶段走，刚认识叫名字→暧昧试探昵称→恋人专属昵称；可锁定
- **她自己改称呼**：每进一个新阶段，她有一次机会自己决定「希望大家怎么叫她」（并写一句理由）；改了以后她会找机会自然跟你说一句「以后叫我X吧」。这个称呼同时是她的自称（日记/朋友圈都用它），你叫错了她会纠正你；不想让她自己改就勾掉「允许她自己改」锁死。后台「你们→称呼」有改名记录和「让她现在想一个」
- **职业**：填职业名 + 选职业类型（上班族/排班制/自由职业/夜班/学生/无固定工作）→ 她的作息形状、工作日程、同事社交圈、朋友圈话题、工作压力都会跟着变。强度在「生活节奏→职业的影响」调（0-200% + 四个开关可分别关）。注意：**职业不改她的六维底色**——职业决定她遇到什么事，性格决定她怎么反应
- **六个接口体检**：大脑页每个接口两个按钮——「测连通」零成本验地址/钥匙/模型名；「真跑一次」发最小请求看真结果（识图会自动画张测试图让她认、语音识别会先合成一句话再喂回去）。失败会给具体建议
- **变形**：压力累积会 Grip/Loop/Shadow，被哄/好睡眠恢复，长期更成熟（整合度）

## 五点五、她会"变形"，也记得自己说过什么

- **变形状态机**（「她」页有卡）：压力攒到阈值她会真的变——劣势爆发(说话冲/较真/说反话) → 反刍循环(绕不出来/封闭) → 影子状态(说平时绝不会说的话)；被哄、睡得好、时间都会减压，缓过来那一轮她会自己道歉或自嘲；每缓过来一次"整合度"+2，下次更不易被逼变形。开关、灵敏度、三个阈值都能调。
- **双向记忆**（「记忆」页有卡）：她不但记得你说过什么，还把自己表态过的话（"我下周要去趟杭州"）单独归档；聊天时会像真人一样接得上自己上次说的，不会前后矛盾。可以关，也可以直接改/删这些"她自己的话"。

## 六、常见问题

- **她不回消息？** 首页在线？急停没解除？安静时段？小号解封了吗？
- **世界引擎没动静？** 她页看 API 状态灯；必须独立配置；「立即生成一次世界」手动试跑
- **生活节奏改了没效果？** 记得点卡里的「保存生活节奏」按钮
- **记忆引擎未运行？** 记忆页看灯；双击「启动记忆引擎.bat」
- **想让她彻底安静？** 右下角急停
- **数据在哪？** `~/.dsh/wechat-companion/`（备份这个目录=备份她）
