## 七、工程坑清单（血泪）

1. **组合页签的子函数禁止 `box.innerHTML=''`**——谁最后结束谁擦掉别人（机务页曾被整页清空，竞态偶发）。
2. **`_sanitizeConfig` 是白名单**：新增配置组不登记就被静默丢弃（曾丢过 embed.baseURL、world.weatherReal、memory.selfMemory、deform.*）。
3. **`_behavior()` 也是白名单函数**：曾把整个 `memory` 组丢掉 → 设置静默失效。
4. **领域关键字段名不匹配**：`info.deformLine` vs 传入的 `deformInfo`（变形曾完全没生效）。
5. **时序**：恢复/道歉指令必须在生成回复"之前"消费，否则永远赶不上那一轮。
6. **元组判定位**：ROLES 里 `ex[1]==='sourceSelect'` 实际在第 3 位 → 「向量来源」下拉从未渲染。
7. **预览窗口尺寸**：`force-device-scale-factor` 会让 CSS 视口缩水（曾只有 952px，截图看不清、只排 2 列）；现用 1560×1180、scale=1。
8. **shell/转义**：大段 JS/CSS 用 `write` 工具写文件再拼接；heredoc 里 `\n`/`\d` 易被吃；Edit 工具锚点要唯一。
9. 工作区改名会让 pnpm 软链全断（`Cannot find package 'silk-wasm'`）；vendored 四件套已实体化。
10. **局部变量遮蔽模块/工具名**（同一类坑踩了三次）：处理函数里的 `path` 遮蔽 node:path（控制台永远伺服旧页面）、tab 函数里的 `bar`/`card` 遮蔽控制台小工具（整块静默失败）、`var f=` 遮蔽字段助手。守卫：console-smoke 的"禁止覆盖全局工具名" + boot-smoke 的"处理函数内禁用 path 模块"。
11. **`let` 声明晚于使用**（TDZ）：`interestLog`/`relLine` 在 `out = {...}` / `sys = [...]` 之后才声明 → `Cannot access X before initialization`。新增字段时先声明再组装。
12. **`loadCfg()` 返回的是配置对象本身**，不是 `{config:{...}}` → 记忆页写成 `rs[1].config` 后永远取到空对象，导致"设置保存了但界面回显不出来"（用户会以为"无法保存"）。经验：保存后要把**后端回传的值写回输入框**，让"保存成功"看得见。
13. **时间窗不能只比大小**：`if (现在 >= 目标时刻) 就发` 会在下午补发早安/晚安（睡觉填 02:00 时全天都算"该睡了"）；跨天窗口要用绝对时间戳判断（`absWindowPhase`）。

### 联动方向（谁影响谁，一句话）
- **世界引擎 → 她的生活**：作息/心情/痴迷/流水/念头/秘密/圈子/长线/印象，全部经提示词或次日 daily 状态影响她的言行。
- **世界引擎 → 记忆**：流水与成长理由写进记忆（`source=life`），所以她"记得自己昨天干了什么"。
- **世界引擎 → 变形机**：只有 workload 这一条（工作负荷≥50 才触发），其余情绪不直接改压力。
- **她 → 世界引擎**：今天的作息/事件、六维、你们的聊天记忆、这周被哄/被怼的次数，都是编剧的素材。
- **性格 → 一切强度**：职业给场景，六维给反应强度（同一件事，不同性格不同后果）。
- **她不知道自己是被"写"出来的**：提示词里明确要求"绝不提 AI/模型/生成"。

### 唯一"乱"的地方（已知并已缓解）
1. **两套作息来源**会打架：世界引擎排了作息就优先（`worldAuthored`），职业机制只在她没剧本时改作息 —— 已在后台写明"世界引擎优先"。
2. **周结算从未跑过**：`evolution.json` 不存在 = 世界引擎一晚都没成功生成过（需要你在「她→她的世界」配独立 API）。机制就绪，但**没有真实数据进来**。
3. **秘密/念头这类"氛围素材"用概率注入**（秘密 15%），不是每次都出现——这是刻意的（否则她像在念剧本），但排查时容易误以为没生效；后台「上帝视角」能直接看到原始数据。
