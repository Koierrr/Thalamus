# 《AI陪伴微信机器人》架构设计 v3（2026-09-11）

## 一、总体形状

她 = 一个 DSH 插件（dsh-wechat-companion）+ 微信载体 + 记忆引擎 sidecar + 世界引擎（独立模型底座）。

```

        │ 收发
┌───────▼────────────────────────────────┐
│ index.js 服务（127.0.0.1:43121 独立服务器）│
│  ├ soul.js      灵魂：提示词/记忆检索/分条/延迟/关系/称呼演变 │
│  ├ daily.js     每日随机："今天的她"（消费世界剧本）        │
│  ├ world-engine.js 世界引擎（独立API槽位 cfg.world）       │
│  ├ deform.js    四层变形状态机（Flex/Grip/Loop/Shadow）    │
```

## 二、世界引擎（独立模型底座）

- 配置：`cfg.world = {baseURL, apiKey, model, weatherReal}`，在「她」页配置；**必须独立，不与对话接口共用、不回落**。
- 触发：她进入睡眠窗口后（`shouldGenerate`）每晚一次；未配置→不转；失败→30分钟退避。
- 产出（world-state.json）：diary / wake+sleep（forDate 指向剧本生效日）/ mood / focus / flow（入记忆 source:life）/ thoughts / secrets / npcs（稳定编制≤6人，按名字去重合并）/ portrait（每晚重写）/ longterm（长线推进）/ weather（真实 Open-Meteo 优先，开关关或失败→她自己编）/ milestone（纪念日）。
- 每周性格结算：距 `evolution.json.lastEvolvedAt` ≥7天时，按 warm/rude/chats 计数微调六维（合计≤±5，每维-2~+2），按 `mbtiTraits` 推导基准钳制 ±25（认知类型永不变），成长理由入记忆，计数器清零。

## 三、每日随机（daily.js）

- 种子=日期+人设指纹，确定性随机；世界引擎剧本（forDate 匹配）优先：作息照剧本、心情绕剧本基线±6、痴迷用剧本。
- 无剧本兜底：作息=基准±jitter×秩序感系数，周末推迟30%~100%随机，夜猫/通宵按概率。
- 六维每日弹性：事件因果漂移（通宵→电量-8~-14 等，硬边界±15），只影响"今天"，基准与八维不变；电量/主动次数由漂移后六维驱动。

## 四、灵魂（soul.js）

- 提示词注入：人设/六维（基准+今日漂移）/MBTI/今日心情痴迷/天气/念头/秘密（15%含糊漏）/社交圈/长线/纪念日/画像/变形状态/自我认知双档卡。
- 称呼：`stageOf(affection)` 阶段决定（0/20/40/55/70/85→恋人），callOwner=恋人阶段专属昵称，callLock=全程锁定；ownerCallsMe=她对你的叫法偏好。
- 检索：mem0 向量 + 本地 JSON either/or；情绪滤镜、语言互染（主人用词）、主人画像。

## 七、黑盒清零批次（2026-09-11 夜）

用户铁律：**做了的功能必须在后台有体现（设置或描述），否则就是黑盒**。

修复的三个"算了没用"半成品：
- **四层变形状态机**：拼提示词时读的和回复时传的**不是同一个字段名**（读的是变形文案、传的却是变形数据）→ 她变形了却从来没影响过回复；另外「刚缓过来」的标记也在生成回复**之后**才调用，恢复指令永远赶不上那一轮；`recoveryNote = chunks[0]` 语义错误且全项目无人消费。现改为：生成前计算 `_deformLine()`（Grip/Loop/Shadow 三档风格指令 + 恢复轮道歉/自嘲指令 + 整合度成长提示）并注入提示词；返回 `recovered` 标记。后台新增「她→变形状态机」卡：说明 + 实时压力/状态/整合度/生效阈值/上次变形/最近事件 + 性格周结算账本 + 开关/灵敏度/三阈值可调。
- **双向记忆**：她自己的自述一直在记，但**检索时从不搜这一类**（只搜联系人本人和通用那两类）→ 她自己说过的话永远想不起来。现在引擎与本地两地两条检索路径都加入 self 一路（按检索来源打标 who/source），提示词里把"她自己的话"与"别人的事"分成两段注入（要求立场一致、可自然延续）。后台「记忆」页新增双向记忆卡：开关 + 她自己的话列表。
- **六维每日弹性**：漂移算出来了但后台看不见 → 实况页新增「📊 今日六维弹性」徽章。
