## 后台设计约定（2026-09-11 起）
- 两级折叠（大分区默认展开、小项默认收起，状态类小项默认展开）+ 每页左侧目录。
- 字段两列自适应（短字段并排、长字段整行）；标签固定宽度右对齐在左，解释写成输入框下的说明行。
- 数值状态用「指标格 + 进度条 + 颜色标签」，不堆成一行长串。
- **组合页签的子函数禁止 `box.innerHTML=''`**（竞态：谁最后结束谁擦掉别人）。
- **后台是交付物**：界面文案不许出现"我的备注口吻"（如"已删掉""两处打架"），交付前必须真渲染自查。
- 回归工具链：`test/run-all.mjs`（全量 29 个，一测一子进程 + 硬超时）、`console-smoke.mjs`（8 页签渲染 + 分区 + 字段下限 + 第三次改版守卫）、`audit-config.mjs`（配置键消费点）、`audit-api.mjs`（接口↔路由 + 分组白名单）、`console-live-check.mjs`（真前端+真后端）、`preview.mjs`（真 Chromium 截图 + 排版指标）、`_probe.mjs`（渲染出可见文字，查"这段话在不在页面上"）。
