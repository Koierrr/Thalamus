## 首页
- ✅ 微信连接：启停/账号列表/扫码绑定/连接自检
- ✅ 今天的她：作息/心情/电量/话痨度/痴迷/压力变形/🌍世界引擎徽章/🌤天气/**📊今日六维弹性**
- ✅ 实况直播（4秒刷新）+ 回复预览（试聊，可计入记忆）

## 她（8 大分区 · 默认展开 · 小项默认收起）
- 🪪 **她是谁**：基础档案（名字/生日/城市/职业/年龄）/ 背景故事 / 兴趣与口头禅 / 说话细节（emoji 比例、手滑打错字）
- 🧠 **性格**：MBTI 底色（→八维→六维，一键重算）/ 六维微调
- ⏰ **生活节奏**：回复速度与作息 / 每天的人味随机（波动±600、夜猫、通宵、周末推迟上限）/ 主动与催促 / **主动消息（总开关·早晚安·分享时段）** + 卡内保存
- 🎭 **她的状态**：指标格（压力条、状态标签、整合度条、生效阈值）+ 上次变形/最近事件/周结算账本 / 原理与参数（开关、灵敏度、三阈值）
- 🌍 **她的世界**：世界引擎 API（必填）/ 纯文字说明 / 运行状态·上帝视角（上次生成、生效日、作息、心情、痴迷、天气、念头、秘密、长线、流水）/ 她的天气 / 她的社交圈
- 📋 **她的能力清单**：功能状态单一数据源（她会什么 / 部分可用 / 还不会什么，她本人聊天时也照这个回答）
- 💾 **存档**：保存与存档 / 历史存档（切换、改名、删除）
- 顶部常显条：保存人设 / 存档名 / 存档为 / 去「你们」页看关系

## 你们（5 大分区）
- 💞 **关系阶段**：指标格（当前阶段、亲密度进度、她的心情、已聊、认识天数、称呼方式）+ 距下一阶段还差多少 + 六阶段阈值表（当前行高亮）+ 所有联系人
- 🏷️ **称呼与关系**：专属昵称（恋人阶段启用）/ 锁定称呼 / 她希望你叫她 + 保存
- 📔 **她的日记**：世界引擎每晚写；空状态写清原因与试跑方法
- 🪞 **她眼中的你（画像）**：可手改，明晚被世界引擎重写，注入对话提示
- 👥 **名单与范围**：回复范围 / 谁是主人👑 / 黑名单 / **安静时段**

## 记忆（4 大分区）
- 🔌 引擎（mem0 状态 + 迁移）
- 🔁 双向记忆（开关 + 她自己的话列表）
- 📚 她记得的事（教她记一件事 / 搜索 / 过滤含"她自己的话"芯片 / 排序 / 导出 / 列表操作）
- ⚙️ 提炼设置（模式 / 独立 BaseURL+Key+模型 / 每次想起几条 / 每几轮整理一次）

## 大脑（3 大分区 · 六个接口都能单独体检）
- 🧠 对话接口（必填）：BaseURL / API Key / 模型名 / 拉取列表
- 🧩 其他接口（可选）：生图 / TTS / ASR / 识图 / 记忆向量（向量来源下拉：本地 Ollama 或云端）
- 🎛️ 通用参数：temperature / 语音条比例 / **聊天机制（最多拆几条、记得最近几轮）** + 保存全部

## 女娲（5 大分区）
- 🧭 怎么用（三步说明）/ 🎭 女娲的 API（选填）/ 💬 和女娲聊（会话切换、新对话、删除）/ 📝 实时草稿（含应用与回写行为建议）

## 机务（4 大分区 · 只管"载体与系统"）
- 📡 **载体与通道**：发送通道（ClawBot / wxauto）、wxauto 启用、桥地址、每日上限、监听名单、桥状态、防封说明
- 🛠️ **系统与备份**：Python 路径 / 自启记忆引擎 / 备份保留天数 / 数据目录 / 配置导出导入
- 🖼️ **媒体（占位）**：允许生图、生图后先过目（等形象工坊落地一起搬走）
- 📷 **朋友圈工坊**：主题生成草稿 / 复制 / 标记已发 / 删除

## 后台设计约定（2026-09-11 起）
- 两级折叠（大分区默认展开、小项默认收起，状态类小项默认展开）+ 每页左侧目录。
- 字段两列自适应（短字段并排、长字段整行）；标签固定宽度右对齐在左，解释写成输入框下的说明行。
- 数值状态用「指标格 + 进度条 + 颜色标签」，不堆成一行长串。
- **组合页签的子函数禁止 `box.innerHTML=''`**（竞态：谁最后结束谁擦掉别人）。
- 回归三件套：`console-smoke.mjs`（7 页签渲染 + 分区 + 字段下限）、`audit-config.mjs`（配置键消费点）、`audit-api.mjs`（接口↔路由 + 配置分组白名单）。
