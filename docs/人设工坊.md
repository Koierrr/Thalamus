# 人设工坊（女娲）v2（2026-09-11）

## 交互形态
- 后台「女娲」页，对话式：你随便说，她追问细节，实时长草稿。
- 多会话管理（新建/切换/删除），会话落盘 workshop-sessions.json。
- 独立API槽位 `cfg.workshop`（可选，留空跟对话接口；专线失败自动回落对话接口——注意：这条回落是女娲的，世界引擎没有回落）。

## 草稿内容（MBTI-only）
- 档案：名字/生日/城市/职业/年龄/背景/兴趣/口头禅/红线/风格样例/记忆种子
- 测评：MBTI 4字母（+认知功能串）→ 六维由八维自动推导；大五/九型已彻底移除
- 外貌（face/hair/style/body/vibe，供后续形象工坊用）
- 行为建议：回复速度/拆条/每日主动/作息
- relationship：toOwner/callOwner

## 应用
- 「①应用到人设+导入记忆」：人设覆盖（自动快照可回滚）+ 记忆种子进 mem0
- 「②行为建议写进人设」：behavior 字段写入
