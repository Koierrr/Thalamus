# 她的记忆系统设计 v2（2026-09-11）

## 一、双层引擎

- **主力：mem0**（本地模式 faiss + bge-m3 嵌入 + 云端便宜模型提炼），sidecar `python/memory_service.py`（:43122）。坑位记录：get_all/search 必须带 user_id 过滤；faiss 维度必须=嵌入维度（bge-m3=1024）；错误缓存靠 mtime 自愈。
- **兜底：本地 JSON**（memory.json）写穿镜像——每条 mem0 写入带 mid 同步落 JSON；引擎挂了自动降级，一条不丢；迁移幂等（按用户+文本去重）。

## 二、记忆的来源（source 徽章）

| source | 谁写的 | 例子 |
|---|---|---|
| 主人说的话 | 对话提炼 | "主人不吃香菜" |
| self | 她自己的关键自述 | 她主动说的心事 |
| life | 世界引擎生活流水/长线/成长理由 | （生活）明天下午开会 |

## 三、检索与注入

- 每轮回复：向量检索 topK 条（interacts 省token：每 N 轮提炼一次）+ 本地兜底，either/or 不合并防重复。
- **情绪滤镜**：心情差时想起的事带刺；**语言互染**：主人常说的词和梗她学进去用；**主人画像**（portrait）：世界引擎每晚结合聊天重写，注入"你对他的印象"。

## 四、性格演化数据

- `evolution.json` 计数器（warm/rude/chats，只统计主人互动），世界引擎每满7天结算一次微调六维并写成长理由（source:life）。

## 五、管理

后台「记忆」页：状态灯 / 迁移 / 添加 / 搜索 / 过滤（按联系人）/ 编辑 / 钉住 / 删除 / 导出 Markdown / 提炼设置（独立 BaseURL+Key+模型）。
